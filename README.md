# AI Security Playground 🛡️

This repo contains hands-on experiments with common AI attacks and defenses.
It's structured for learning and sharing results in a clear, reproducible way.

## Topics Covered
1. Prompt Injection (LLM attacks)
2. Adversarial Examples (FGSM, PGD)
3. Data Poisoning & Backdoors
4. Privacy Attacks (Membership Inference)
5. Basic Defenses (Adversarial Training, Input Sanitization)

## How to Use
- Each folder has a README explaining the attack, steps, and references.
- Run notebooks with Python 3.10+ and install dependencies via:
  ```bash
  pip install -r requirements.txt
